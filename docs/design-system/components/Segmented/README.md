# Segmented

A segmented control switches between views of the same thing: Plan ↔ 3D on the stage, Day ↔ Night, Warm ↔ Amber.

Two to four options, each a short noun with an optional icon. The pressed segment is caramel tape (`caramel`, `on-caramel`, `caramel-edge` lip) on a `surface-sunken` track; on the stage the track is `surface`. Use it only when every option shows the same object; to move between steps use StepNav, to choose a value from a list use a select Field.
