# Segmented

A segmented control switches between views of the same thing: Plan ↔ 3D on the stage, Day ↔ Night, Warm ↔ Amber.

Two to four options, each a short noun with an optional icon. The pressed segment uses `surface` on a `surface-sunken` track. Use it only when every option shows the same object; to move between steps use StepNav, to choose a value from a list use a select Field.
