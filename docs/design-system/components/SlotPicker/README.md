# SlotPicker

The fit test: a drawn comb with five numbered slots around the board's nominal thickness, and one button per slot. Picking the snug slot calibrates the material, and every joint in the kit resizes to it.

Show the comb drawing above the buttons so the numbers match the physical piece. The chosen slot is pressed (`mat`). After a pick, show a success Notice saying what changed ("Chipboard 2 mm set to 2.10 mm — every joint now fits that board"). The consumer provides the material and its slot widths.
