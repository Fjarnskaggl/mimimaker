# Notice

An inline message about the thing in front of you. Four tones plus light, each with its icon **and** a bold word, so colour is never the only signal:

- info (`mat-soft`, info icon): helpful context.
- success (`success-soft`, check): "**Calibrated.** Every joint now fits 2.10 mm board."
- warning (`warning-soft`, alert): needs a look but won't stop a cut.
- danger (`danger-soft`, alert): will stop the cut; say how to fix it.
- light (`glow-soft`): lighting tips on the Light step only.

One sentence, two at most. Offer the fix as a quiet button on the right. Problems with other things go to the Checks pill, never a stack of banners above the stage.
