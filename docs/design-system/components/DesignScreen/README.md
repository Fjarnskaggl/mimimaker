# DesignScreen

The Design step laid out with the system: header (mark, kit name, StepNav, compact KitMeter, Checks pill, Undo, Share), a three-button tool rail, the stage with view switches, and the Inspector on the selected piece.

Compare with today's app: the room box, windows, furniture list, lighting, materials and five tabs all showed at once. Here the stage gets the space, and settings appear only for what is selected. See the Flow section for where every old control moved.
