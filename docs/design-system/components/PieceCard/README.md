# PieceCard

A tile in the library drawer: a thumbnail from the renderer, the piece name, and two facts — difficulty (three dots plus the word in the tooltip) and part count in `measure`.

Clicking adds the piece to the room and selects it, so the Inspector opens on it. Cards sit in a 3-column `.mm-grid` in the drawer. Never put prices, ratings or more than two facts on a card. The consumer provides thumbnail, name, level (1–3) and part count.
