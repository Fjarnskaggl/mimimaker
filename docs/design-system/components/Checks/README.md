# Checks

All of a kit's problems live behind one pill in the header: a dot (success, warning or danger), the word and a count — "All good", "2 to check", "1 blocks cutting". Clicking opens a popover listing each problem with its icon, a one-line title, a hint and a link that selects the thing on the stage.

This replaces warning banners stacked above the stage. Info-level tips never go here; they appear inline where relevant, or not at all.
