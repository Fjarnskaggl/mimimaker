# SheetCard

One material sheet on the Make step: material swatch and name, the sheet drawing (cut lines in `ink` on `kraft`, folds dashed in `score`), file buttons for the chosen machine, and a footer with size and cut time in `measure`.

The machine decides the buttons: Cricut gets one SVG; laser gets SVG and DXF. Show the Design Space setting or laser note once per sheet in the footer, not in a paragraph. The consumer provides the sheet preview, material, files and estimates.
